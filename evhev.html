01 / PROJECT CONTEXT

What the project addresses

Built a Rome urban-traffic simulation workflow using SUMO route data and Python interfaces linked with MATLAB/Simulink EV and HEV models. The project contains multiple traffic intensities, vehicle-model files and saved scenario results.

02 / ENGINEERING METHOD

Method and implementation

  • Prepared light, medium and heavy traffic scenarios with SUMO-compatible routes.
  • Connected traffic speed traces and vehicle simulation via Python/MATLAB bridging scripts.
  • Compared speed tracking, state-of-charge trends and energy/fuel-equivalent outputs across scenarios.
03 / RESULTS

Evidence and observations

  • Archived CSV summaries contain light, medium and heavy scenarios and actual-versus-reference speed records.
  • Separate EV and HEV Simulink models and scenario plots are included.
04 / CRITICAL REVIEW

Scope and limitations

Saved scenario results have not been independently rerun in the current environment; do not interpret equivalent-fuel quantities as laboratory vehicle measurements.

PROJECT RECORD

Supporting evidence

Project RAR contains Python scripts, MATLAB bridges, .slx models, route files, result CSVs and figures.
