# Reza Babapiri — Engineering Portfolio (v2)

This is a static site ready for `reza-babapiri.github.io`. It has five thematic collections, thirteen source-derived case studies, individual pages, and downloadable PDFs for each discipline.

## Upload through GitHub website
1. Open https://github.com/reza-babapiri/reza-babapiri.github.io
2. Select **Add file > Upload files**.
3. Extract the ZIP locally. Upload the **contents** of the `site` directory (not the parent folder or the ZIP itself), retaining `projects/`, `assets/`, `pdfs/`, and `code/`.
4. Commit to the `main` branch. Your configured GitHub Pages should rebuild automatically.
5. Visit https://reza-babapiri.github.io and test the category PDF links and project pages.

**Important:** Source code and academic reports have not been independently executed in the publishing environment. Public source is curated and student IDs are redacted from readable code. The Buck Simulink models are provided in a separate downloadable ZIP within `code/`; inspect before publishing if any project files or metadata should remain private. Raw course reports and company proprietary drawings are NOT published.

The original documents have overlapping mathematical demonstrations and course-reproduction tasks. Claims are deliberately limited to what the supplied files support. The V6 engine and planetary gearbox are explicitly marked as not completed. Robot Sumo and AI moss detection await their own code / outputs.

## Structure
- `index.html` landing page and cross-category navigation
- `projects/*.html` in-depth case studies
- `assets/projects/*.png` source-derived images and clearly labeled illustrations
- `pdfs/*.pdf` individual category portfolio PDFs and overview
- `code/` selected source scripts and Buck source package
- `styles.css`, `script.js`, `favicon.svg`

## Privacy and attribution
This site omits raw course reports that show student numbers or team members. The Obstacle Avoiding Robot is described as a two-person course project. External course materials, datasheets and proprietary employer drawings have not been copied into this website. Please review the files before making them public.
