Autonomous Obstacle-Avoiding Robot

Arduino Uno, ultrasonic sensing, servo scanning and DC motor driving

ArduinoHC-SR04Embedded C++L298N
FIGURE FROM SUPPLIED PROJECT MATERIAL
01 / PROJECT CONTEXT

What the project addresses

Documented an obstacle-avoiding mobile robot assembled for an embedded systems course by a two-person team. A servo-mounted ultrasonic sensor scans the front and sides and an Arduino Uno drives motors through an L298N module.

02 / ENGINEERING METHOD

Method and implementation

  • Integrated Arduino Uno, HC-SR04 ultrasonic sensor, servo motor and dual DC geared motors.
  • Implemented repeated distance sampling with out-of-range filtering and averaging.
  • Used motor-control functions and threshold-based obstacle detection to stop, reverse and turn.
03 / RESULTS

Evidence and observations

  • Report documents a 40 cm front obstacle threshold and timing-based drive commands.
  • Full Arduino source and a wiring diagram are present in the supplied group report.
04 / CRITICAL REVIEW

Scope and limitations

The report describes choosing the clearer side, but the supplied final loop alternates turning with turnCounter. This inconsistency is disclosed rather than presenting unverified path planning.

Supporting evidence
